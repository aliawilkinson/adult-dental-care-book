# Release Notes: v0.1.0

Release date: 2026-07-16

## Summary

This release establishes the repository as a full book-production workspace for **The Adult Teeth Guide: How to Keep Your Teeth Healthy for Life**.

It creates the structure, standing instructions, research policy, international evidence workflow, review files, and Codex cloud task prompt needed to draft the manuscript chapter by chapter instead of treating the book as one giant prompt.

## What Changed

- Created durable agent instructions for future Codex work.
- Added the approved book outline and author voice reference.
- Added editorial rules to preserve the direct, practical, non-institutional voice.
- Added a claims policy that separates evidence, consensus, emerging research, disputed interpretations, and author preference.
- Added an international oral-health research standard so the book does not default to U.S. dental guidance as universal authority.
- Added research files for international outcomes, guideline comparison, evidence ledger, claim mapping, unresolved evidence, and nano-hydroxyapatite review.
- Added review files for progress tracking, source needs, author decisions, manuscript planning, and international bias audit.
- Added the current dental care regimen as a happy-path source artifact.
- Added a paste-ready overnight Codex cloud task prompt.
- Added the initial `book/full-manuscript.md` placeholder and chapter directory.

## SemVer Meaning

`0.1.0` means the repository workflow and drafting plan are ready, but the manuscript itself is not yet drafted.

## Next Milestone

`0.2.0` should represent a completed first-draft manuscript generated from the outline, with populated research files, review reports, source needs, and assembled full manuscript.
